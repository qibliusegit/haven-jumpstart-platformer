# bwaa-ception #
tl;dr a platformer where you collect bwaas as a bwaa while moving on bwaas.

I thought it'd be cool if I made a game where I used the same texture for as many things as I can, so I decided to make this! I used the 'bwaa' meme from Bocchi the Rock as much as I could (literally everything outside of 
text and the title screen/background).

It actually taught me a lot about Godot, since I hadn't used tilemaps before and also hadn't messed much with printing variables to the screen.

# HOW TO PLAY #
Use WASD/Arrow Keys to move and jump (you can also use space to jump)
Collect 20 'bwaas' to win!
